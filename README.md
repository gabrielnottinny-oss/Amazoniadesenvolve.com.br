# Amazônia Desenvolve — Sistema de Gestão Social

Aplicação Django para gestão de municípios, polos, comunidades, famílias, visitas domiciliares e acompanhamentos sociais.

## Estado

Repositório inicializado. O código da versão 5 **ainda não foi publicado neste repositório**; homologação e migrações PostgreSQL pendentes.

## Segurança

Não versionar `.env`, `SECRET_KEY`, `DATABASE_URL`, credenciais, backups, documentos ou informações pessoais de beneficiários. A visibilidade pública do código não autoriza exposição de dados. Configurar variáveis secretas somente no Render.

## Próximos passos

Enviar o conteúdo do pacote Django v5 revisado, configurar PostgreSQL de homologação e executar testes de autenticação e isolamento territorial antes de usar dados reais.
